# おぼえてタッチ

脳卒中などで高次脳機能障害のある大人向けの、ワーキングメモリー訓練アプリです。
ブラウザだけで動く1ファイルのWebアプリで、iPad・スマートフォン・PCで使えます。

## 特徴

- **暮らしの12場面の課題**：ワーキングメモリーの要素ごとに、生活に近い場面で練習します

| 鍛える力 | 課題 |
|---|---|
| ことば・手順の記憶（系列スパン） | スーパーで買い物／カレー作り |
| 数字の記憶（数唱） | 電話番号のメモ（聴覚提示）／コインロッカー（視覚提示） |
| 位置の記憶（視空間スパン） | 星空（Corsi型）／神経衰弱 |
| 記憶の更新（n-back） | 回転寿司／駅のホーム |
| 記憶＋計算（メンタルトラッキング） | バスの乗客数／お財布の中身 |
| 組み合わせの記憶（結びつけ） | お薬カレンダー／予定の伝言 |

- **適応的難易度**：2回連続正解でレベルが上がり、2回連続で間違えると下がります（n-back課題はヒット率と誤反応で調整）
- **日替わりトレーニング**：5・7・10分のあいだ、しばらく実施していない課題から順に出題します
- **個別練習**：12課題のどれか1つを、1ラウンド・3分・5分で練習できます
- **逆順（上級）**：順番を答える課題を、逆の順で答えるモードに切り替えられます
- 効果音・読み上げ・BGM、提示の速さ（ゆっくり／標準／速い）を設定できます
- 複数の利用者を切り替えて、レベル・記録・設定を別々に保存できます。記録はグラフ表示とCSVコピーに対応しています

## 使い方

公開URL：https://just-ot-goodful.github.io/oboete-touch/ （iPadやスマートフォンのブラウザでそのまま開けます）

`index.html` をブラウザで開くだけで動きます。GitHub Pagesを有効にすると、URLからiPadで開けます。

## 注意

- 記録は、使っている端末のブラウザの中（localStorage）だけに保存されます。別の端末とは共有されません。
- 利用者名は、氏名ではなくイニシャルやIDでの登録をおすすめします。
- このアプリは検査（評価）の代わりにはならず、医療機器ではありません。療法士が隣について使うことを想定しています。

## 開発

編集対象は `src/oboete-touch.html` のみです。`index.html` はそこから自動生成される
ビルド済みファイルなので直接編集しないでください。

```bash
npm install      # 初回のみ
python3 build.py # src/oboete-touch.html → index.html を生成
```

詳しい構成・既知の制約・修正履歴は [CLAUDE.md](./CLAUDE.md) を参照してください。
